What this deployment actually runs

The local deployment uses an Express gateway and a gRPC storage service. S3 is an optional third replica; Kubernetes and Terraform configuration are available in the source.

Replication acknowledges an upload when at least one replica accepts each chunk. It does not guarantee both copies if a node is offline. Each chunk's random IV and authentication tag live in metadata. SHA-256 verifies the reconstructed file.
